Sample 1 · Investments Landscape

An investor earns a nominal return of 10% when inflation is 6%. Using the exact Fisher relationship, the real return is approximately:

  1. 4.00%
  2. 16.00%
  3. 6.00%
  4. 3.77%
Show answer & explanation

Answer: D. 3.77%

Real return = (1.10 / 1.06) − 1 ≈ 3.77%.

Sample 2 · Types of Investments

Which of these is a hybrid security combining features of debt and equity?

  1. Treasury bill
  2. Equity share
  3. Compulsorily convertible debenture
  4. Commercial paper
Show answer & explanation

Answer: C. Compulsorily convertible debenture

A CCD pays interest like debt and later converts into equity, which is why it is widely used in PE deals.

Sample 3 · Concept of Informational Efficiency

If prices fully reflect all publicly available information, so that fundamental analysis of published data cannot consistently earn excess returns, the market is:

  1. Weak form efficient only
  2. Strong form efficient
  3. Inefficient
  4. Semi-strong form efficient
Show answer & explanation

Answer: D. Semi-strong form efficient

Semi-strong efficiency means public information (including financial statements) is already in prices.

Sample 4 · Introduction to Modern Portfolio Theory

Two assets each have standard deviation of 20% and correlation of +1. A 50:50 portfolio of them will have a standard deviation of:

  1. 10%
  2. 20%
  3. 14.1%
  4. 0%
Show answer & explanation

Answer: B. 20%

With perfect positive correlation there is no diversification benefit; portfolio σ is the weighted average, 20%.

Sample 5 · Introduction to Capital Market Theory

Using CAPM, if the risk-free rate is 6%, the expected market return is 12% and a fund's beta is 1.2, its required return is:

  1. 14.4%
  2. 12.0%
  3. 13.2%
  4. 7.2%
Show answer & explanation

Answer: C. 13.2%

Required return = 6% + 1.2 × (12% − 6%) = 6% + 7.2% = 13.2%.
