Fee Structure and Fund Performance: NISM Series XIX-E practice questions

8 free questions with answers and explanations on Fee Structure and Fund Performance, from the NISM Series XIX-E (Category III Alternative Investment Fund Managers) syllabus.

Last updated 20 November 2026 · By the Success4Sure editorial team · How we create questions

What this chapter covers

This chapter covers how Category III funds charge investors and how their performance is measured. Fee items include management fees, performance fees (carry), hurdle rates, catch-up, high-water marks, set-up and operating expenses and distribution commissions. Performance tools include absolute and annualised returns, time-weighted and money-weighted returns, drawdown, Sharpe, Sortino, Treynor, information ratio and alpha. Practise computing net-of-fee returns and risk-adjusted ratios, and understand which measure suits which situation.

Fee Structure and Fund Performance questions

Question 1

A fund's NAV peaked at ₹150, fell to ₹120, then recovered to ₹135. A high-water mark of ₹150 means the manager can charge a performance fee:

  1. On the ₹15 recovery from ₹120 to ₹135
  2. On any positive return in the calendar year
  3. Only on gains after NAV rises above ₹150
  4. On the full NAV every quarter
Show answer & explanation

Answer: C. Only on gains after NAV rises above ₹150

A high-water mark ensures performance fees are paid only on new highs, so investors do not pay twice for recovering earlier losses. The ₹120 to ₹135 recovery attracts no performance fee.

Question 2

A fund returned 14% with a downside deviation of 8%. The risk-free rate is 6%. Its Sortino ratio is:

  1. 1.75
  2. 1.00
  3. 0.75
  4. 2.33
Show answer & explanation

Answer: B. 1.00

Sortino = (return − risk-free) / downside deviation = (14 − 6) / 8 = 1.00. It penalises only harmful volatility, unlike the Sharpe ratio, which uses total standard deviation.

Question 3

A fund's NAV goes from ₹100 to ₹140 and then falls to ₹105. The maximum drawdown is:

  1. 35%
  2. 5%
  3. 25%
  4. 40%
Show answer & explanation

Answer: C. 25%

Maximum drawdown is the largest peak-to-trough fall: (140 − 105) / 140 = 25%. It is measured from the peak, not the starting NAV, so it is not 35% or 5%.

Question 4

A gross return of 20% is subject to a 2% management fee and then a 20% performance fee on the remaining return (no hurdle). The approximate net return is:

  1. 16.0%
  2. 14.4%
  3. 18.0%
  4. 12.0%
Show answer & explanation

Answer: B. 14.4%

After the management fee, return = 20 − 2 = 18%. Performance fee = 20% × 18 = 3.6%. Net = 18 − 3.6 = 14.4%. This simplified sequence ignores timing and compounding of fee accruals.

Question 5

A 'hurdle rate' in a performance fee arrangement means:

  1. The manager's management fee is waived in a falling market
  2. The manager earns a performance fee only if returns exceed a set minimum
  3. The investor must pay a fixed fee every year regardless of how the fund has actually performed
  4. Redemptions are allowed only above a certain NAV level
Show answer & explanation

Answer: B. The manager earns a performance fee only if returns exceed a set minimum

A hurdle sets a minimum return investors must receive before carry applies. It protects investors from paying performance fees on modest returns they could earn elsewhere.

Question 6

When should money-weighted return (IRR) rather than time-weighted return be used to judge performance?

  1. When the manager controls the timing of investor cash flows, as in drawdown funds
  2. When investors themselves decide when to subscribe and redeem, as in a typical open-ended fund
  3. When comparing two funds with exactly identical cash flows each day
  4. When the fund has no cash flows during the whole year
Show answer & explanation

Answer: A. When the manager controls the timing of investor cash flows, as in drawdown funds

IRR reflects the timing and size of cash flows. In close-ended drawdown funds, the manager decides when to call and return money, so IRR is appropriate. TWR suits open-ended funds where investors control flows.

Question 7

Two funds have the same Sharpe ratio. Fund X has a lower beta than Fund Y. For an investor holding a well-diversified main portfolio, Fund X will have a:

  1. Lower Treynor ratio, regardless of excess return
  2. Higher standard deviation than Fund Y
  3. Higher Treynor ratio, if both have the same excess return
  4. Lower information ratio by definition
Show answer & explanation

Answer: C. Higher Treynor ratio, if both have the same excess return

Treynor = excess return / beta. With the same excess return, the fund with lower beta earns more per unit of market risk. Sharpe uses total risk, so the two ratios can rank funds differently.

Question 8

A fund returned 11% against a benchmark return of 9%, with tracking error of 5%. The information ratio is:

  1. 2.00
  2. 0.40
  3. 0.22
  4. 1.80
Show answer & explanation

Answer: B. 0.40

Information ratio = active return / tracking error = (11 − 9) / 5 = 0.40. It measures how consistently the manager adds value relative to the benchmark.
