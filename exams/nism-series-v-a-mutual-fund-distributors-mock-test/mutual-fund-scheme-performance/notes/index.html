Mutual Fund Scheme Performance: NISM Series V-A revision notes

Once a scheme has a track record, investors need to judge it against a benchmark and peers. This chapter covers benchmark selection, the Total Return Index, risk-adjusted measures and how returns are presented. Questions test which measure to use in which situation and include short calculations of Sharpe ratio or tracking error concepts.

Last updated 20 November 2026 · By the Success4Sure editorial team · Free

Key points

1. Purpose of a benchmark

A benchmark shows what a passive investment in the same market segment would have earned. A large cap fund is compared with an index such as Nifty 100 or BSE 100, not with a small cap index or a bank FD.

2. Total Return Index

SEBI requires schemes to benchmark against the Total Return Index (TRI), which assumes dividends are reinvested. Comparing a fund with a price-only index flatters the fund because the index ignores dividends. A price index may lag the TRI by 1-1.5% a year because it ignores dividends paid by constituent companies.

3. Tiered benchmarks

SEBI introduced a two-tier benchmark structure: the first tier reflects the category (common for all funds in that category), and an optional second tier reflects the fund's own style. This makes comparisons across fund houses fairer. Both tiers must be disclosed in documents.

4. Peer comparison

Funds should be compared with others in the same SEBI category. Comparing a liquid fund's return with a small cap fund's is meaningless because their objectives and risks differ completely. Even within equity, a mid cap fund should be compared with mid cap peers and a mid cap index, not with large cap funds or the Nifty 50.

5. Sharpe ratio

Sharpe = (fund return - risk-free rate) / standard deviation. A fund returning 14% with SD 16% and risk-free rate 6% has a Sharpe ratio of 0.5. Higher is better; it rewards return per unit of total risk. It suits concentrated or partly diversified funds.

6. Treynor ratio and alpha

Treynor = (fund return - risk-free rate) / beta, suitable for diversified portfolios. Alpha is the excess return over what the fund's beta would predict; positive alpha signals manager skill, at least for that period. Alpha from one year can be luck rather than skill.

7. Tracking error

Tracking error is the standard deviation of the difference between a fund's return and its benchmark's. Index funds and ETFs aim to minimise it; causes include expenses, cash holdings and delays in rebalancing. A tracking error of 0.1% is excellent for an index fund; 1% would suggest poor replication or high costs relative to peers.

8. SIP returns and rolling returns

SIP returns are computed with XIRR because each instalment is invested at a different date. Rolling returns show performance over many overlapping periods, revealing consistency better than a single point-to-point figure. For example, three-year rolling returns calculated daily over ten years show how often a fund beat its benchmark, not just whether it did so once.

Formulas and rules of thumb

  • Sharpe = (Rp - Rf) / Standard deviation
  • Treynor = (Rp - Rf) / Beta
  • Jensen's alpha = Rp - [Rf + Beta x (Rm - Rf)]

Common traps in the exam

  • Comparing a fund with a price-return index instead of the TRI, which overstates outperformance.
  • Using Treynor for a concentrated, undiversified fund - Sharpe is the better measure there.
  • Assuming a fund with the highest one-year return is the best; check consistency and risk-adjusted returns.
  • Confusing tracking error (volatility of the difference) with simply the return gap in one year.

Quick recap

Benchmark = what passive investing in the same segment earned; use TRI. Compare within the SEBI category. Sharpe uses SD, Treynor uses beta, alpha measures excess over beta-predicted return. Tracking error matters for index funds. Use XIRR for SIPs and rolling returns for consistency.
