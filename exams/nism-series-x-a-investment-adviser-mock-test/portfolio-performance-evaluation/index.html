Portfolio Performance Evaluation: NISM Series X-A practice questions

8 free questions with answers and explanations on Portfolio Performance Evaluation, from the NISM Series X-A (Investment Adviser (Level 1)) syllabus.

Last updated 23 November 2026 · By the Success4Sure editorial team · How we create questions

What this chapter covers

This chapter covers how to measure and judge portfolio performance: holding period return, time-weighted and money-weighted returns, annualisation, benchmarks, and risk-adjusted measures such as Sharpe, Treynor, Jensen's alpha, Sortino and information ratio, along with tracking error. When revising, practise each formula with numbers, understand which measure suits a diversified versus concentrated portfolio, and learn why returns must always be compared with a suitable benchmark and adjusted for risk.

Portfolio Performance Evaluation questions

Question 1

A fund returned 12% when the risk-free rate was 6%. Its downside deviation was 8%. What is its Sortino ratio?

  1. 0.75
  2. 1.50
  3. 0.50
  4. 2.00
Show answer & explanation

Answer: A. 0.75

Sortino ratio = (portfolio return − risk-free rate) ÷ downside deviation = (12 − 6) ÷ 8 = 0.75. Unlike Sharpe, it penalises only downside volatility.

Question 2

A fund beat its benchmark by 2% a year with a tracking error of 4%. What is its information ratio?

  1. 2.0
  2. 8.0
  3. 0.5
  4. 0.08
Show answer & explanation

Answer: C. 0.5

Information ratio = active return ÷ tracking error = 2 ÷ 4 = 0.5. It measures how consistently a manager adds return over the benchmark per unit of active risk.

Question 3

Which return measure removes the effect of the timing of investor cash flows and is preferred for judging a fund manager?

  1. Money-weighted return
  2. Simple absolute return
  3. Dividend yield
  4. Time-weighted return
Show answer & explanation

Answer: D. Time-weighted return

Time-weighted return links sub-period returns, so it is not distorted by when investors add or withdraw money, which the manager does not control. Money-weighted return (IRR) reflects the investor's own timing.

Question 4

For a well-diversified portfolio, which risk-adjusted measure uses beta as the measure of risk?

  1. Sharpe ratio
  2. Treynor ratio
  3. Sortino ratio
  4. Information ratio
Show answer & explanation

Answer: B. Treynor ratio

The Treynor ratio divides excess return by beta, focusing on systematic risk, which is appropriate when unsystematic risk has been diversified away. Sharpe uses total standard deviation.

Question 5

An investment gave a return of 21% over two years. Its annualised (compound) return is closest to:

  1. 10.5%
  2. 21.0%
  3. 10.0%
  4. 11.0%
Show answer & explanation

Answer: C. 10.0%

Annualised return = (1.21)^(1/2) − 1 = 10%. Dividing 21% by two gives 10.5%, which ignores compounding and overstates the yearly rate.

Question 6

Why must a mid-cap fund be compared with a mid-cap index rather than the Nifty 50?

  1. The benchmark must match the fund's universe
  2. The Nifty 50 is not a valid index
  3. Mid-cap indices always give higher returns
  4. SEBI bans comparison with large-cap indices
Show answer & explanation

Answer: A. The benchmark must match the fund's universe

A benchmark should reflect the fund's investment universe and risk. Comparing a mid-cap fund with a large-cap index mixes style effects with manager skill.

Question 7

Tracking error of an index fund measures:

  1. The fund's expense ratio
  2. The index's average return
  3. The number of stocks in the index
  4. Volatility of the fund's return gap
Show answer & explanation

Answer: D. Volatility of the fund's return gap

Tracking error is the standard deviation of the difference between fund and index returns, showing how consistently the fund replicates its benchmark. Lower is better for an index fund.

Question 8

Two funds have equal returns. Fund X has a higher standard deviation than Fund Y. Based on the Sharpe ratio:

  1. Fund X has better risk-adjusted return
  2. Fund Y has better risk-adjusted return
  3. Both have identical risk-adjusted returns
  4. The Sharpe ratio cannot compare them
Show answer & explanation

Answer: B. Fund Y has better risk-adjusted return

With the same excess return, the fund with lower standard deviation has a higher Sharpe ratio. Fund Y delivered the same return for less total risk.
