Portfolio Performance Evaluation: NISM Series X-A revision notes

Advisers must report performance honestly and judge whether a portfolio or fund is adding value. This chapter covers return measures for different cash flow patterns and risk-adjusted ratios. Calculation questions are common: memorise the formulas and practise with the numbers below.

Last updated 20 November 2026 · By the Success4Sure editorial team · Free

Key points

1. Holding period return

HPR = (ending value - beginning value + income) / beginning value. A ₹1 lakh investment worth ₹1.12 lakh after a year with ₹2,000 of dividends gave a 14% HPR. It ignores the time taken, so annualise it for comparisons.

2. CAGR and XIRR

CAGR suits a single lump sum: ₹1 lakh becoming ₹2 lakh in six years is about 12.2% a year. When there are multiple cash flows at different dates, such as SIPs, withdrawals and top-ups, XIRR gives the correct annualised return.

3. Time-weighted vs money-weighted

Time-weighted return removes the effect of client deposits and withdrawals, so it measures the manager's skill. Money-weighted return (IRR or XIRR) reflects the client's actual experience, including the timing of their contributions. If a client adds a large sum just before a market fall, the money-weighted return will look much worse than the time-weighted return of the same fund.

4. Sharpe ratio

Sharpe = (portfolio return - risk-free rate) / standard deviation. A fund returning 14% with SD 16% and a 6% risk-free rate has a Sharpe ratio of 0.5. It uses total risk, so it suits evaluating a client's whole portfolio.

5. Treynor ratio

Treynor = (portfolio return - risk-free rate) / beta. A fund earning 13% with beta 1.4 and risk-free 6% has a Treynor ratio of 5. It uses only systematic risk, so it suits well-diversified portfolios that are part of a larger holding.

6. Jensen's alpha

Alpha = actual return - [risk-free + beta x (market return - risk-free)]. A fund with beta 1.2 earning 15% when the market returned 12% and risk-free was 6% has expected return 6 + 1.2 x 6 = 13.2%, so alpha is 1.8%.

7. Sortino and information ratio

Sortino ratio divides excess return by downside deviation only, so it does not penalise upside volatility. Information ratio = active return / tracking error, showing how consistently a manager beats the benchmark per unit of active risk. Higher values are better for both ratios.

8. Benchmarks and attribution

Performance means little without a suitable benchmark: a blended benchmark for a 60:40 portfolio, or the TRI for an equity fund. Attribution analysis splits excess return into allocation effect and security selection effect. This tells the adviser whether outperformance came from choosing the right asset mix or from picking the right securities within each asset class.

Formulas and rules of thumb

  • Sharpe = (Rp - Rf) / σp
  • Treynor = (Rp - Rf) / βp
  • Jensen's alpha = Rp - [Rf + βp x (Rm - Rf)]
  • Information ratio = (Rp - Rb) / Tracking error

Common traps in the exam

  • Using Treynor for a concentrated, undiversified portfolio - Sharpe is more appropriate because unsystematic risk remains.
  • Using CAGR for a portfolio with many SIP contributions; XIRR is needed.
  • Forgetting to subtract the risk-free rate before dividing in Sharpe or Treynor.
  • Computing alpha as fund return minus market return, ignoring beta.

Quick recap

HPR for one period; CAGR for lump sums; XIRR for multiple cash flows. Time-weighted judges the manager, money-weighted reflects the client. Sharpe uses SD, Treynor uses beta, alpha adjusts for beta, Sortino uses downside risk, information ratio uses tracking error. Always compare with a suitable benchmark.
