Logarithm Rules and Tricks for CAT and Other MBA Exams

Logarithms are a core algebra topic in CAT, CMAT and MAT, typically giving one or two questions, and they also appear in SSC CGL Tier 2 and some RBI Grade B papers. Questions are usually short — evaluate an expression, solve a log equation or count the digits of a large power — but each one tests whether the basic laws are second nature. Treat a logarithm simply as an exponent and most questions become easy.

Last updated 20 November 2026 · By the Success4Sure editorial team · Free

Definition

log_a N = x means aˣ = N, with a > 0, a ≠ 1 and N > 0. So log₂ 64 = 6 because 2⁶ = 64. Common logarithms use base 10 (log 1000 = 3); natural logarithms use base e. log_a 1 = 0 and log_a a = 1 for any valid base.

log_a N = x ⇔ aˣ = N

Laws

log(mn) = log m + log n; log(m/n) = log m − log n; log(mᵖ) = p log m. These let you break numbers into primes: log 72 = log(2³ × 3²) = 3 log 2 + 2 log 3. With log 2 ≈ 0.3010 and log 3 ≈ 0.4771, log 72 ≈ 1.8572.

log mⁿ = n log m

Change of base

log_a b = log b / log a in any common base. A useful consequence is log_a b × log_b c = log_a c, so chains of logs collapse: log₂ 3 × log₃ 32 = log₂ 32 = 5. Also log_a b = 1/log_b a.

log_a b = log_c b / log_c a

Equations with logs

To solve a log equation, combine logs on each side into a single log using the laws, then convert to exponential form. For log x + log(x − 3) = 1 (base 10), write log[x(x − 3)] = 1, so x² − 3x = 10 and x = 5 or −2. Reject −2 because log of a negative number is undefined.

Number of digits

The number of digits in a positive integer N is ⌊log₁₀ N⌋ + 1. For 2⁵⁰, log = 50 × 0.30103 ≈ 15.05, so 2⁵⁰ has 16 digits. This is a classic CAT-style application.

Digits = ⌊log N⌋ + 1

Shortcuts and tricks

  • log 2 ≈ 0.3010, log 3 ≈ 0.4771, log 7 ≈ 0.8451; log 5 = 1 − log 2 ≈ 0.6990.
  • log 4 + log 25 = log 100 = 2 — look for pairs that multiply to powers of 10.
  • In log equations, always check that the arguments stay positive for your solution.
  • log_a b = log_{aⁿ} bⁿ — useful to match bases like 4 and 2.
  • If log_a x = log_a y, then x = y; equal logs with equal bases mean equal arguments.

Worked examples

Example 1

Evaluate log₂ 64.

Solution

Ask "2 to what power gives 64?" Since 2⁶ = 64, log₂ 64 = 6. Reading every logarithm as a question about exponents is the quickest way to evaluate simple logs.

Example 2

Evaluate log 8 + log 125 (base 10).

Solution

Adding logs multiplies the arguments: log 8 + log 125 = log(8 × 125) = log 1,000 = 3. Spotting that 8 × 125 is a power of 10 is the whole trick; computing each log separately would need tables.

Example 3

Evaluate log₃ 81 − log₃ 9.

Solution

Subtracting logs divides the arguments: log₃(81/9) = log₃ 9 = 2. Alternatively, 4 − 2 = 2, since log₃ 81 = 4 and log₃ 9 = 2.

Example 4

Given log 2 = 0.3010 and log 3 = 0.4771, find log 72.

Solution

72 = 2³ × 3². log 72 = 3 × 0.3010 + 2 × 0.4771 = 0.9030 + 0.9542 = 1.8572.

Example 5

How many digits does 2⁵⁰ have? (log 2 = 0.30103)

Solution

log 2⁵⁰ = 50 × 0.30103 = 15.05. Digits = 15 + 1 = 16.

Example 6

Solve log₂(x + 3) = 4.

Solution

x + 3 = 2⁴ = 16, so x = 13. The argument 16 is positive, so the solution is valid.

Practice questions

Question 1

log₅ 625 = ?

  1. 5
  2. 3
  3. 25
  4. 4
Show answer & explanation

Answer: D. 4

Since 5⁴ = 625, the logarithm of 625 to base 5 equals 4 by definition.

Question 2

log 4 + log 25 (base 10) = ?

  1. 2
  2. 1
  3. 29
  4. 100
Show answer & explanation

Answer: A. 2

Adding logs multiplies the arguments: 4 × 25 = 100, and log 100 = 2 in base 10.

Question 3

log₂ 3 × log₃ 32 = ?

  1. 3
  2. 6
  3. 32
  4. 5
Show answer & explanation

Answer: D. 5

The chain rule gives log₂ 32 = 5, because the intermediate base 3 cancels out.

Question 4

If log 2 = 0.3010 and log 3 = 0.4771, then log 18 = ?

  1. 1.0791
  2. 0.7781
  3. 1.2552
  4. 1.5562
Show answer & explanation

Answer: C. 1.2552

18 = 2 × 3², so log 18 = 0.3010 + 2 × 0.4771 = 0.3010 + 0.9542 = 1.2552.

Question 5

How many digits does 3²⁰ have? (log 3 = 0.4771)

  1. 9
  2. 10
  3. 11
  4. 20
Show answer & explanation

Answer: B. 10

log 3²⁰ = 20 × 0.4771 = 9.542, so the number of digits is 9 + 1 = 10.

FAQs

Why can’t the logarithm of a negative number be taken?

Because a positive base raised to any real power is always positive, so no real exponent gives a negative or zero result. That is why log equations require positive arguments, and solutions that make an argument negative must be rejected.

Do I need to memorise log tables?

No full tables are needed. Knowing log 2, log 3 and log 7 to four decimal places lets you compute logs of most composite numbers used in exams, since log 5 = 1 − log 2 and others follow from the laws.
