Analogy in Reasoning: Word, Letter and Number Pairs

Analogy questions ask you to find a pair that is related in the same way as a given pair. SSC CGL, CHSL and MTS ask two or three analogy questions in almost every reasoning paper, mixing word, letter and number types. Bank exams use them less often, mostly in clerk-level papers. The key is to state the relationship in a short sentence before looking at the options, which stops the options from pulling you towards a near-miss.

Last updated 23 November 2026 · By the Success4Sure editorial team · Free

Word analogies

Common relationships: worker and tool (carpenter : saw), product and raw material (paper : pulp), part and whole (petal : flower), animal and young (cow : calf), country and currency (Japan : yen), instrument and measurement (thermometer : temperature). Say the relation as a sentence: 'A carpenter uses a saw.'

Letter analogies

Check the shift between corresponding letters. ACE : CEG is +2 for each letter, so BDF : DFH. Also check reversal, opposite letters (sum 27) and position-sum relations.

Number analogies

Typical links are square (7 : 49), cube (4 : 64), square plus one (8 : 65), n³ + n (3 : 30), or multiples. Test the simplest operation first and confirm with the second pair before choosing.

Order matters

'Doctor : hospital' is not the same as 'hospital : doctor'. The answer pair must keep the same direction of relation.

Mixed and two-step analogies

SSC papers sometimes combine operations: a letter pair may reverse the word and then shift each letter, or a number pair may use 'square of the digit sum'. If no single operation fits, try two steps in the most natural order — reverse then shift, or add digits then square. Always verify the rule on the given pair before applying it to the option pair, because two different rules can fit the first number by chance.

Number-pair options

Some questions ask you to choose the pair that matches the given pair, for example 'Find the pair like 4 : 17'. Here 17 = 4² + 1, so 6 : 37 fits, while 6 : 36 does not. Check every option fully; a pair that matches only one part of the rule is a deliberate distractor.

Shortcuts and tricks

  • Make a sentence with the first pair, then plug each option into the same sentence.
  • For letter pairs, write positions above the letters; most patterns become obvious with numbers.
  • Memorise squares up to 30 and cubes up to 15 — most number analogies use them.
  • If two options fit a broad relation, look for a more specific one (both are tools, but only one is used by that worker).
  • For country-capital or country-currency pairs, recall only stable static facts.
  • If a letter pair looks random, check opposite letters first: A pairs with Z, B with Y, and each pair adds up to 27.

Worked examples

Example 1

ACE : CEG :: BDF : ?

Solution

Each letter of ACE moves +2 to give CEG. Applying +2 to B, D, F gives D, F, H. Answer: DFH.

Example 2

7 : 49 :: 9 : ?

Solution

49 is 7². So the answer is 9² = 81.

Example 3

Carpenter : Saw :: Tailor : ?

Solution

A carpenter works with a saw. A tailor works with a needle (or scissors). Among options like cloth, needle, shop and thread, 'needle' is the tool, so it is the best answer; cloth is the material, not the tool.

Example 4

3 : 30 :: 5 : ?

Solution

3³ + 3 = 27 + 3 = 30. For 5: 5³ + 5 = 125 + 5 = 130.

Example 5

FISH : GJTI :: LAMP : ?

Solution

Each letter moves +1: F→G, I→J, S→T, H→I. For LAMP: M, B, N, Q. Answer: MBNQ.

Example 6

Doctor : Hospital :: Teacher : ?

Solution

The relation is 'person : place of work'. A teacher works in a school. Options such as student, book or classroom are related to teaching, but only 'school' matches the workplace relation at the same level as 'hospital'.

Practice questions

Question 1

11 : 122 :: 8 : ?

  1. 64
  2. 65
  3. 72
  4. 63
Show answer & explanation

Answer: B. 65

122 equals 11 squared plus one. Applying the same rule to 8 gives 8 squared plus one, which is 65.

Question 2

Cow : Calf :: Dog : ?

  1. Kitten
  2. Cub
  3. Puppy
  4. Foal
Show answer & explanation

Answer: C. Puppy

A calf is the young one of a cow. The young one of a dog is called a puppy; kitten, cub and foal belong to other animals.

Question 3

6 : 216 :: 4 : ?

  1. 16
  2. 48
  3. 256
  4. 64
Show answer & explanation

Answer: D. 64

216 is the cube of 6. The cube of 4 is 4 × 4 × 4 = 64, so 64 completes the analogy.

Question 4

DH : 4,8 :: FL : ?

  1. 6,12
  2. 6,11
  3. 5,12
  4. 7,12
Show answer & explanation

Answer: A. 6,12

The numbers are the alphabet positions of the letters: D is 4 and H is 8. F is 6 and L is 12.

Question 5

Thermometer : Temperature :: Barometer : ?

  1. Humidity
  2. Atmospheric pressure
  3. Wind speed
  4. Rainfall
Show answer & explanation

Answer: B. Atmospheric pressure

A thermometer measures temperature, and a barometer measures atmospheric pressure. Humidity, wind speed and rainfall need other instruments.

FAQs

What if two options seem to fit the analogy?

Look for a closer match to the specific relationship. 'Carpenter : saw' is 'worker : main tool', so 'tailor : needle' beats 'tailor : cloth'. If both still fit, check the order of the pair and any extra pattern such as letter count or category.

How do I improve at word analogies?

Group common relationships — tool, product, young one, home, currency, unit of measurement — and learn a handful of examples in each. Reading a little every day also builds vocabulary that helps in both analogy and English sections.
