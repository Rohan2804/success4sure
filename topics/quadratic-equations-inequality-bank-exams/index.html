Quadratic Equations for Bank Exams: Compare x and y Fast

In IBPS PO, IBPS Clerk, SBI Clerk and RBI Assistant prelims, quadratic equations usually appear as a block of five questions: two equations are given, one in x and one in y, and you must decide whether x > y, x < y, x ≥ y, x ≤ y, x = y or no relation can be established. Each question takes 30–40 seconds once factorisation is automatic. CAT and SSC CGL test quadratics differently, through sum and product of roots.

Last updated 23 November 2026 · By the Success4Sure editorial team · Free

Factorisation by splitting

For x² + bx + c, find two numbers whose product is c and sum is b. For ax² + bx + c, find two numbers whose product is a × c and sum is b, then split the middle term. 2x² − 7x + 3: product 6, sum −7 → −6 and −1, giving (2x − 1)(x − 3) and roots 1/2 and 3.

Sign method for roots

For x² + bx + c with integer roots: if both b and c are positive, both roots are negative; if b is negative and c positive, both roots are positive; if c is negative, the roots have opposite signs. This tells you the signs before you calculate, and often decides the relation immediately.

Comparing the roots

Compare every value of x with every value of y. If all x values are greater, x > y. If some x equals some y and the rest are greater, x ≥ y. If the comparison goes both ways, the answer is "no relation". Placing the roots on a number line makes this visual.

Sum and product of roots

For ax² + bx + c = 0, sum of roots = −b/a and product = c/a. A quadratic with roots p and q is x² − (p + q)x + pq = 0. These relations are tested in SSC CGL and CAT.

Sum = −b/a; Product = c/a

Shortcuts and tricks

  • x² = k gives x = ±√k, but y = √k gives only the positive root — a favourite trap.
  • If both equations have the same sign pattern, compare the magnitudes of the roots directly.
  • Common roots between x and y equations usually produce ≥ or ≤, not > or <.
  • For linear equations in x and y given together, solve them simultaneously instead of factorising.
  • Write roots as fractions, not decimals, so equality is easy to spot.

Worked examples

Example 1

I. x² − 7x + 12 = 0 II. y² − 3y + 2 = 0

Solution

x: (x − 3)(x − 4) = 0, so x = 3, 4. y: (y − 1)(y − 2) = 0, so y = 1, 2. Every x is greater than every y: x > y.

Example 2

I. x² + 5x + 6 = 0 II. y² + 7y + 12 = 0

Solution

x = −2, −3 and y = −3, −4. Comparing: −2 > −3, −2 > −4, −3 = −3, −3 > −4. All comparisons give x greater or equal, so x ≥ y.

Example 3

I. 2x² − 7x + 3 = 0 II. y² − 4y + 3 = 0

Solution

x = 1/2, 3 and y = 1, 3. x = 1/2 is less than y = 1, but x = 3 is greater than y = 1. The relation cannot be established.

Example 4

I. x² = 81 II. y = √81

Solution

x = ±9, while y = +9 only (the square-root symbol means the principal root). x = −9 < 9 and x = 9 = 9, so x ≤ y.

Example 5

The roots of x² − 11x + 28 = 0 are p and q. Form the quadratic whose roots are p − 2 and q − 2.

Solution

p = 4 and q = 7, so the new roots are 2 and 5. Equation: x² − (2 + 5)x + 2 × 5 = x² − 7x + 10 = 0.

Practice questions

Question 1

I. x² − 9x + 20 = 0 II. y² − 5y + 6 = 0. The relation is:

  1. x < y
  2. x ≥ y
  3. x > y
  4. No relation
Show answer & explanation

Answer: C. x > y

x = 4, 5 and y = 2, 3, so every value of x exceeds every value of y and x > y.

Question 2

I. x² + 9x + 20 = 0 II. y² + 7y + 12 = 0. The relation is:

  1. x ≤ y
  2. x > y
  3. x ≥ y
  4. x < y
Show answer & explanation

Answer: A. x ≤ y

x = −4, −5 and y = −3, −4; the common value −4 gives equality and all others give x < y.

Question 3

I. x² − x − 6 = 0 II. y² − 4 = 0. The relation is:

  1. x > y
  2. x ≥ y
  3. No relation
  4. x ≤ y
Show answer & explanation

Answer: C. No relation

x = 3, −2 and y = 2, −2; x = 3 exceeds both y values but x = −2 is below y = 2, so no single relation holds.

Question 4

The sum of the roots of 3x² − 12x + 5 = 0 is:

  1. −4
  2. 5/3
  3. 12
  4. 4
Show answer & explanation

Answer: D. 4

Sum of roots = −b/a = 12/3 = 4, without needing to find the roots themselves.

Question 5

I. 3x² − 10x + 8 = 0 II. 2y² − 11y + 15 = 0. The relation is:

  1. x < y
  2. x > y
  3. x ≤ y
  4. No relation
Show answer & explanation

Answer: A. x < y

x = 4/3, 2 and y = 5/2, 3, so the largest x (2) is still below the smallest y (2.5): x < y.

FAQs

Why is y = √81 only +9 while x² = 81 gives ±9?

The radical sign √ denotes the principal (non-negative) square root by convention, so √81 = 9. The equation x² = 81 asks for every number whose square is 81, which includes −9. Bank exams use this difference deliberately to create ≤ or ≥ answers.

What if a quadratic does not factorise neatly?

In bank comparison questions the roots are almost always rational, so if splitting fails, recheck the product and sum. For general quadratics, use the formula x = (−b ± √(b² − 4ac))/2a. A negative discriminant means no real roots.
