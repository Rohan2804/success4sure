Mirror and Water Images: Letters, Words and Clock Faces

Mirror and water image questions are part of the non-verbal reasoning that SSC CGL, CHSL and MTS papers include in almost every shift, usually one or two questions. Bank exams rarely use them. Most questions show a figure, word or number and ask for its reflection. Figure-based questions need visual practice, but word, letter, number and clock questions can be solved by rule, which makes them quick and reliable marks if you know which way each reflection flips.

Last updated 20 November 2026 · By the Success4Sure editorial team · Free

Mirror image (vertical mirror)

A mirror placed to the right or left of an object reverses left and right but keeps top and bottom. A word's letters appear in reverse order and each letter is flipped sideways. The top of the word remains on top.

Water image (horizontal mirror)

Water below an object reverses top and bottom but keeps left and right. Letters stay in the same left-to-right order but each one appears upside down, as if reflected in a lake.

Letters with symmetry

Letters with a vertical line of symmetry look the same in a mirror: A, H, I, M, O, T, U, V, W, X, Y. Letters with a horizontal line of symmetry look the same in water: B, C, D, E, H, I, K, O, X. H, I, O and X are unchanged in both.

Words that look identical

A word looks the same in a mirror only if it reads the same backwards and every letter has vertical symmetry, such as WOW or TOT. A word looks the same in water if every letter has horizontal symmetry, such as BOX or CHECK, because order does not change.

Shortcuts and tricks

  • Mirror reverses left–right; water reverses up–down. Never both, unless the question asks for a mirror image of a water image.
  • Clock in a mirror: subtract the time from 11:60. 3:40 appears as 8:20.
  • Digits 0 and 8 look the same in both mirror and water images (in standard print), which makes them common distractors.
  • For figure questions, track one distinctive feature (a dot, a shaded corner) rather than the whole figure.
  • When options differ only in one small part, check that part's direction after reflection.

Worked examples

Example 1

Which of these words will look exactly the same in a vertical mirror: WOW, BOB, NUN, DAD?

Solution

A mirror reverses the order and flips each letter sideways. All four words are palindromes, so order is not a problem. But B, N and D are not symmetric left-to-right, so they change. W and O are symmetric. Only WOW looks the same.

Example 2

Which of these words will look the same in water: BOX, TOY, MAN, RUN?

Solution

In water, order stays the same and each letter flips upside down. B, O and X have horizontal symmetry, so BOX is unchanged. T, Y, M, A, R, U and N all change when flipped. Answer: BOX.

Example 3

A clock shows 3:40. What time does its mirror image show?

Solution

Subtract from 11:60: 11:60 − 3:40 = 8:20.

Example 4

Will the word TOMATO look the same in a vertical mirror?

Solution

Every letter (T, O, M, A) has vertical symmetry, so each letter looks the same. But the mirror reverses the order, giving OTAMOT, which is a different word. So TOMATO does not look the same, even though no letter changes shape.

Example 5

Which option shows the mirror image of the number string 1 0 8 0?

Solution

A vertical mirror reverses the order, giving 0 8 0 1, and flips each digit sideways. 0 and 8 look unchanged, but 1 becomes a reversed 1 (its flag points the other way). So the correct option shows 0 8 0 followed by a reversed 1; an option showing a normal 1 is the usual trap.

Practice questions

Question 1

Which letter looks the same in both a mirror image and a water image?

  1. B
  2. U
  3. H
  4. K
Show answer & explanation

Answer: C. H

H has both a vertical and a horizontal line of symmetry. B and K are symmetric only top-to-bottom, and U only left-to-right.

Question 2

Which word looks the same in a water image?

  1. TOY
  2. RUN
  3. MAN
  4. BOX
Show answer & explanation

Answer: D. BOX

A water image keeps letter order and flips each letter upside down. B, O and X are symmetric about a horizontal line, so BOX stays the same.

Question 3

In the word APEX, which letters change shape in a vertical mirror?

  1. P and E
  2. A and X
  3. Only E
  4. All four letters
Show answer & explanation

Answer: A. P and E

A and X have vertical symmetry and look the same in a mirror. P and E are not symmetric left to right, so they appear flipped.

Question 4

A wall clock shows 2:15. What time does its mirror image show?

  1. 10:45
  2. 9:45
  3. 9:15
  4. 10:15
Show answer & explanation

Answer: B. 9:45

Mirror time equals 11:60 minus the actual time. Subtracting 2:15 from 11:60 gives 9:45.

Question 5

What does a water image do to a word written left to right?

  1. Reverses the order of letters
  2. Reverses order and flips letters sideways
  3. Flips each letter upside down but keeps the order
  4. Leaves the word unchanged
Show answer & explanation

Answer: C. Flips each letter upside down but keeps the order

Water acts as a horizontal mirror below the word, so top and bottom swap for each letter, while the left-to-right order of the letters stays the same.

FAQs

How should I practise figure-based mirror questions?

Pick one feature that is not symmetric — a dot near one corner, an arrow, a shaded triangle — and ask where it moves after reflection. Eliminate options where that feature is wrong. Daily practice of ten figure questions for two weeks builds the visual sense needed for SSC papers.

Are mirror images of numbers asked?

Yes, especially number strings like 2 5 8 3. Reverse the order and flip each digit sideways. Digits 0 and 8 look unchanged; 2, 3, 4, 5, 6, 7 and 9 change. Options often differ by a single flipped digit, so check each one carefully.
