Coding-Decoding Tricks: Letter Shift, Opposites, Word Codes

Coding-decoding is tested in IBPS and SBI prelims, RBI Grade B, and every SSC tier that has a reasoning paper. Bank exams prefer sentence-based 'new pattern' coding sets of three to five questions, while SSC asks single letter-shift or number-coding questions. The topic is very learnable because the patterns repeat: once you know alphabet positions by heart and can spot a reversed word, most questions fall in under a minute.

Last updated 20 November 2026 · By the Success4Sure editorial team · Free

Alphabet positions and opposites

Know A=1 to Z=26 forward and backward. Opposite letters always add to 27: A–Z, B–Y, M–N. A quick memory aid is EJOTY for 5, 10, 15, 20, 25. With these two facts you can decode most letter-based codes without writing the full alphabet.

Letter shifting

Each letter moves forward or backward by a fixed number (+1, −2) or by a changing number (+1, +2, +3...). Compare the first two letters of the word and its code, then confirm the rule on the third letter before applying it to the new word.

Reversal and mixed operations

Examiners combine steps: reverse the word, then shift each letter; or swap the first and second halves, then shift. If a simple shift does not fit, check whether the code read backwards matches the word shifted.

Sentence (word) coding

Several sentences are coded word for word, but the code order is jumbled. Find the word common to two sentences and the code common to the same two sentences; they belong together. Continue by elimination. Bank exams often add a twist where each code is built from the first letter of the word plus a number.

Number coding

A word may be coded as the sum, product or concatenation of letter positions. CAT as 24 means 3 + 1 + 20. Test the simplest operation (sum) first.

Shortcuts and tricks

  • Opposite-letter check: if each pair of letter and code adds to 27, it is an opposite code. B(2) and Y(25) → 27.
  • If the code length equals the word length but the letters look unrelated, try reversing the code first.
  • In sentence coding, a word that appears in only one sentence cannot be fixed unless all other words of that sentence are decoded.
  • Write positions above letters for long words; it avoids counting errors under time pressure.
  • When the shift changes (+1, +2, +3), the code is usually built position by position, so write the increments under each letter.

Worked examples

Example 1

If MANGO is written as NBOHP, how is APPLE written in that code?

Solution

M→N, A→B, N→O, G→H, O→P: each letter moves +1. Apply to APPLE: A→B, P→Q, P→Q, L→M, E→F. Code: BQQMF.

Example 2

In a code, BANK is written as YZMP. How is LOAN written?

Solution

B(2)+Y(25) = 27, A(1)+Z(26) = 27, N(14)+M(13) = 27. It is an opposite-letter code. L→O, O→L, A→Z, N→M. LOAN = OLZM.

Example 3

'sun rises early' is 'ka pi mo', 'early bird sings' is 'mo tu ra', and 'bird sun flies' is 'tu ka zo'. What is the code for 'rises'?

Solution

'early' is common to sentences 1 and 2, as is 'mo', so early = mo. 'sun' is common to 1 and 3, as is 'ka', so sun = ka. The only code left in sentence 1 is 'pi', so rises = pi.

Example 4

If CAT is coded as 24, what is the code for DOG?

Solution

C(3) + A(1) + T(20) = 24, so the code is the sum of positions. D(4) + O(15) + G(7) = 26.

Example 5

If STOCK is written as LDPUT, how is BOND written?

Solution

Reverse STOCK to get KCOTS, then shift each letter +1: K→L, C→D, O→P, T→U, S→T = LDPUT. For BOND: reverse to DNOB, shift +1 to get EOPC.

Practice questions

Question 1

If FIRM is written as GJSN, how is BANK written in that code?

  1. CBML
  2. ABOL
  3. CBOL
  4. DCPM
Show answer & explanation

Answer: C. CBOL

Each letter of FIRM moves one step forward in the alphabet. Applying +1 to B, A, N, K gives C, B, O, L, so the code is CBOL.

Question 2

In a code where each letter is replaced by its opposite letter (A↔Z, B↔Y and so on), how is GOLD written?

  1. TLOX
  2. SLOW
  3. TMOW
  4. TLOW
Show answer & explanation

Answer: D. TLOW

Opposite letters add up to 27. G(7)→T(20), O(15)→L(12), L(12)→O(15), D(4)→W(23). The code is TLOW.

Question 3

'loan rate high' is 'pa ki lo', 'rate cut soon' is 'ki mu ze', and 'soon loan approved' is 'ze pa ro'. What is the code for 'high'?

  1. lo
  2. pa
  3. ki
  4. ze
Show answer & explanation

Answer: A. lo

Rate = ki (common to sentences 1 and 2) and loan = pa (common to 1 and 3). The remaining code in the first sentence, lo, must stand for high.

Question 4

If BAT is coded as 23, what is the code for CAR?

  1. 21
  2. 22
  3. 24
  4. 23
Show answer & explanation

Answer: B. 22

BAT gives 2 + 1 + 20 = 23, so letters are replaced by their positions and added. CAR gives 3 + 1 + 18 = 22.

Question 5

If TRADE is written as FEBSU, how is PRICE written in that code?

  1. QSJDF
  2. DBHQO
  3. FDJSQ
  4. FDJRQ
Show answer & explanation

Answer: C. FDJSQ

TRADE reversed is EDART and each letter then moves +1 to give FEBSU. PRICE reversed is ECIRP; shifting each letter +1 gives FDJSQ.

FAQs

How do I memorise alphabet positions quickly?

Learn the anchor letters E(5), J(10), O(15), T(20), Y(25) using the word EJOTY, then count one or two steps from the nearest anchor. Pair this with the rule that opposite letters add to 27. A week of five-minute daily drills is usually enough to make positions automatic.

Why do bank exams have sentence-based coding instead of letter shifts?

Sentence coding tests elimination and attention rather than simple counting, and it lets the examiner ask three or more questions from one set of statements. SSC still prefers single letter-shift questions. Practise both, but give extra time to sentence coding if you are targeting IBPS or SBI.
