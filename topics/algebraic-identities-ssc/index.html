Algebraic Identities for SSC: x + 1/x and Cube Tricks

Algebra carries real weight in SSC CGL Tier 1 and Tier 2 and SSC CHSL, where three to five questions test identities such as x + 1/x, a³ + b³ and the a + b + c = 0 rule. CAT and CMAT also rely on them. Bank exams rarely ask algebra directly, but the same identities speed up simplification. Almost every question becomes a one- or two-line substitution once you know which identity to apply.

Last updated 19 November 2026 · By the Success4Sure editorial team · Free

Square identities

(a + b)² = a² + 2ab + b²; (a − b)² = a² − 2ab + b²; a² − b² = (a + b)(a − b). From a + b and ab you can find a² + b² = (a + b)² − 2ab and (a − b)² = (a + b)² − 4ab.

a² + b² = (a + b)² − 2ab

Cube identities

(a + b)³ = a³ + b³ + 3ab(a + b), so a³ + b³ = (a + b)³ − 3ab(a + b). Similarly a³ − b³ = (a − b)³ + 3ab(a − b). These turn cube questions into arithmetic once a ± b and ab are known.

a³ + b³ = (a + b)³ − 3ab(a + b)

The x + 1/x family

If x + 1/x = k, then x² + 1/x² = k² − 2 and x³ + 1/x³ = k³ − 3k. If x − 1/x = k, then x² + 1/x² = k² + 2. For higher powers, square again: x⁴ + 1/x⁴ = (x² + 1/x²)² − 2.

x³ + 1/x³ = k³ − 3k

The a + b + c = 0 rule

a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca). So if a + b + c = 0, then a³ + b³ + c³ = 3abc. With 1, 2 and −3: 1 + 8 − 27 = −18 = 3 × 1 × 2 × (−3).

If a + b + c = 0: a³ + b³ + c³ = 3abc

Shortcuts and tricks

  • Products near round numbers: 998 × 1002 = 1000² − 2² = 9,99,996.
  • 101² − 99² = 200 × 2 = 400 — difference of squares beats squaring.
  • Test identity questions with simple values like x = 1 or a = 1, b = 0 to eliminate options.
  • If x + 1/x = 2, then x = 1 and every power sum xⁿ + 1/xⁿ = 2.
  • If x + 1/x = −2, x = −1; alternating signs appear for odd powers.

Worked examples

Example 1

If x + 1/x = 5, find x² + 1/x² and x³ + 1/x³.

Solution

x² + 1/x² = 25 − 2 = 23. x³ + 1/x³ = 125 − 3 × 5 = 110.

Example 2

If a + b = 10 and ab = 21, find a² + b² and a − b.

Solution

a² + b² = 100 − 42 = 58. (a − b)² = 100 − 84 = 16, so a − b = ±4 (the numbers are 7 and 3).

Example 3

Find a³ + b³ + c³ if a = 1, b = 2, c = −3.

Solution

a + b + c = 0, so a³ + b³ + c³ = 3abc = 3 × 1 × 2 × (−3) = −18. Direct check: 1 + 8 − 27 = −18.

Example 4

Evaluate 101² − 99².

Solution

(101 + 99)(101 − 99) = 200 × 2 = 400.

Example 5

If x − 1/x = 3, find x² + 1/x².

Solution

Square both sides: x² − 2 + 1/x² = 9, so x² + 1/x² = 11.

Practice questions

Question 1

If x + 1/x = 4, then x² + 1/x² = ?

  1. 16
  2. 18
  3. 14
  4. 12
Show answer & explanation

Answer: C. 14

Square both sides: x² + 2 + 1/x² = 16, so x² + 1/x² = 14.

Question 2

If a + b = 7 and ab = 12, then a² + b² = ?

  1. 49
  2. 25
  3. 37
  4. 24
Show answer & explanation

Answer: B. 25

a² + b² = (a + b)² − 2ab = 49 − 24 = 25, consistent with a = 3 and b = 4.

Question 3

If x + 1/x = 3, then x³ + 1/x³ = ?

  1. 27
  2. 24
  3. 18
  4. 36
Show answer & explanation

Answer: C. 18

Use k³ − 3k with k = 3: 27 − 9 = 18 for the sum of cubes and reciprocal cubes.

Question 4

998 × 1002 = ?

  1. 9,99,999
  2. 9,99,996
  3. 10,00,004
  4. 9,99,004
Show answer & explanation

Answer: B. 9,99,996

Write it as (1000 − 2)(1000 + 2) = 1,000,000 − 4 = 9,99,996 using a² − b².

Question 5

If a − b = 3 and ab = 10, then a³ − b³ = ?

  1. 117
  2. 27
  3. 90
  4. 63
Show answer & explanation

Answer: A. 117

a³ − b³ = (a − b)³ + 3ab(a − b) = 27 + 90 = 117, matching a = 5 and b = 2.

FAQs

Why do SSC exams ask so many x + 1/x questions?

Because they test whether a student can manipulate identities rather than solve for x, which is often irrational. A few standard results — k² − 2, k³ − 3k — answer most variants in seconds, so they are good discriminators of preparation.

Can I solve identity questions by picking numbers?

Often yes. If a question holds for all values satisfying a condition, choose simple values that meet it, such as a = 1, b = 2, c = −3 for a + b + c = 0, and test each option. Use this when the algebra seems long.
